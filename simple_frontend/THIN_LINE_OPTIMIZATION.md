# 细线交互优化说明

## 问题描述
矢量线很细时，有时候指针变成pointer了，但是单击不会出现属性框。这是因为细线的拾取区域太小，用户难以准确点击。

## 优化方案

### 1. 基于ID的可靠交互机制 ⭐ **核心改进**
- **悬停状态管理**：新增`hoverState`变量，专门管理悬停时的要素信息
- **ID一致性保证**：确保鼠标指针变化和点击响应使用相同的要素ID
- **状态同步**：悬停时存储要素ID，点击时优先使用悬停状态中的ID
- **双重保障**：图层级别和全局级别的悬停处理，确保不遗漏

### 2. 预加载机制
- **悬停时预加载**：在鼠标悬停时就预生成要素ID和弹窗内容，减少点击时的计算延迟
- **缓存要素信息**：将悬停时的要素信息缓存，点击时直接使用，提高响应速度

### 3. 拾取容差优化
- **增加最小线宽**：将最小线宽从1像素增加到2像素，提高细线的可见性
- **动态拾取半径**：根据要素类型动态调整拾取半径
  - 细线要素：8像素拾取半径
  - 普通要素：5像素拾取半径
- **增加点半径**：将最小点半径从2像素增加到3像素

### 4. 视觉反馈增强
- **悬停提示**：为细线要素添加tooltip提示，显示"点击查看属性"
- **高亮效果**：启用Deck.gl的内置高亮功能，悬停时显示黄色高亮
- **cursor样式**：确保鼠标指针正确显示为pointer

### 5. 交互逻辑优化
- **集成处理**：将点击逻辑集成到悬停处理中，确保交互一致性
- **双重处理**：同时支持图层级别和全局级别的悬停处理
- **快速响应**：利用预加载的数据，点击时立即显示弹窗

## 技术实现

### 核心函数
1. `isThinLineFeature()` - 检测细线要素
2. `getPickableRadiusForFeature()` - 获取动态拾取半径
3. `handleLayerHover()` - 增强的悬停处理（基于ID）
4. `handleMapClick()` - 优化的点击处理（优先使用悬停ID）
5. `debugHoverState()` - 调试悬停状态

### 新增状态管理
```javascript
// 悬停状态管理 - 确保指针变化和点击响应的一致性
const hoverState = ref({
  hoveredFeatureId: null,    // 当前悬停的要素ID
  hoveredFeature: null,      // 当前悬停的要素对象
  hoveredLayer: null,        // 当前悬停的图层
  hoveredCoordinate: null,   // 当前悬停的坐标
  popupContent: '',          // 预生成的弹窗内容
  isHovering: false          // 是否正在悬停
})
```

### 配置参数
```javascript
// MVT图层配置
lineWidthMinPixels: 2,        // 最小线宽
pointRadiusMinPixels: 3,      // 最小点半径
pickable: true,               // 启用拾取
getPickableRadius: (feature) => getPickableRadiusForFeature(feature), // 动态拾取半径
autoHighlight: true,          // 启用高亮
highlightColor: [255, 255, 0, 100] // 黄色高亮
```

## 核心改进点

### 🔥 基于ID的可靠交互
1. **悬停时存储ID**：鼠标悬停时立即生成并存储要素ID
2. **点击时使用ID**：点击时优先使用悬停状态中的ID，确保一致性
3. **状态同步**：悬停状态和选中状态完全同步
4. **双重保障**：图层级别和全局级别的处理确保不遗漏

### 🔥 绝对避免指针变化但点击无响应
- 只有在悬停状态中有要素ID时，才会显示pointer指针
- 点击时优先使用悬停状态中的要素信息
- 如果悬停状态为空，则不会显示pointer指针
- 确保指针变化和点击响应的100%一致性

## 效果
- ✅ 细线更容易被点击
- ✅ 点击响应更快
- ✅ 视觉反馈更清晰
- ✅ 用户体验更流畅
- ✅ **绝对避免指针变化但点击无响应的情况**

## 兼容性
- 支持所有类型的矢量要素（点、线、面）
- 特别优化了LineString和MultiLineString类型
- 保持与现有功能的兼容性
- 向后兼容，不影响现有功能
